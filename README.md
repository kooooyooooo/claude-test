# 選手コンディショニング可視化アプリ（デモ版）

小学生ハンドボールチーム向けのコンディショニング管理アプリです。  
主観的疲労度(RPE)から自動的にsRPE負荷とACWRを計算し、選手のリスク状態を信号色で可視化します。

## 機能

### 選手モード
- 日次の練習記録を入力（練習時間、RPE、メモ）
- 自分の過去7日の記録を表示

### コーチモード（管理者ダッシュボード）
- 全選手のACWRを信号色付きで一覧表示
  - 🟢 **緑（適正）**: 0.8 ≦ ACWR ≦ 1.3
  - 🟡 **黄（注意）**: 0.5〜0.8 または 1.3〜1.5
  - 🔴 **赤（高リスク）**: < 0.5 または > 1.5
- リスク状態の集計
- 選手詳細画面で過去35日の負荷とACWR推移をグラフ表示

## ACWR計算ロジック

- **sRPE（日次負荷）** = 練習時間(分) × RPE(1〜10)
- **Acute負荷（急性）** = 直近7日のsRPE平均
- **Chronic負荷（慢性）** = 直近28日のsRPE平均
- **ACWR** = Acute ÷ Chronic

## セットアップ

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev

# ビルド
npm run build
```

## デプロイ（GitHub Pages）

```bash
# ビルド
npm run build

# dist/フォルダを gh-pages ブランチにデプロイ
npx gh-pages -d dist
```

## データについて

- 本番運用には LocalStorage や実SQLite への差し替えを推奨
